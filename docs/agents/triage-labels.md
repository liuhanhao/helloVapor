# 分类标签（Triage Labels）

各 skill 使用五个规范的分类角色（triage role）来表述。本文件将这些角色映射到本仓库 issue 跟踪系统中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们跟踪系统中的标签 | 含义                                     |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此 issue                   |
| `needs-info`               | `needs-info`         | 等待提交者提供更多信息                   |
| `ready-for-agent`          | `ready-for-agent`    | 已完整描述，可交给离线代理（AFK agent）处理 |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现                             |
| `wontfix`                  | `wontfix`            | 不会处理                                 |

当某个 skill 提及某个角色时（例如"应用 AFK-ready 分类标签"），使用本表右侧列对应的标签字符串。

编辑右侧列以匹配你实际使用的词汇表。
