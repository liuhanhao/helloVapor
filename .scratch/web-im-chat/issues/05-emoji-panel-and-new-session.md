# 05 — emoji 面板与发起新会话

**要构建的内容：** 用户能通过输入框旁的 emoji 选择面板把 Unicode emoji 插入文本并发送（emoji 即普通文本消息，无协议扩展）；也能主动发起与一个尚无任何聊天记录的用户的新会话——输入对方账号或 userid 查询，找到后在会话列表建立条目并开始聊天。服务端新增按账号/用户 ID 查询用户的接口（返回公开身份信息，不泄露密码相关字段）。图标按需取自 koboyo.com/icons 的 SVG。

**被阻塞于（Blocked by）：** 01 — 曳光弹：文本消息端到端跑通；02 — 会话列表与历史消息

**状态（Status）：** ready-for-agent

- [ ] 输入框旁有 emoji 面板，点击可把 Unicode emoji 插入输入框并随文本发送
- [ ] 对端正确收到并渲染含 emoji 的文本消息
- [ ] 可输入对方账号或 userid 查询用户，查到后发起新会话
- [ ] 查询不到用户时有明确提示
- [ ] 新会话条目出现在会话列表中，可正常收发消息
- [ ] 用户查询接口不返回密码等敏感字段
